SILENCE — нативный Android Studio starter project (v0.1.0)

Что реализовано в исходниках:
- экран приложения SILENCE;
- запрос системного разрешения Android MediaProjection;
- запуск foreground service с типом mediaProjection;
- остановка сеанса захвата;
- голосовой вывод через Android TextToSpeech;
- запрос разрешения на уведомления Android 13+.

Что НЕ реализовано:
- извлечение кадров и OCR/распознавание графика;
- получение реальных котировок;
- анализ UP/DOWN с подтверждённой статистикой;
- интеграция с Binomo;
- автоматические нажатия/сделки;
- Telegram/SMS отправка.

Открыть в Android Studio (желательно актуальная версия), дождаться Gradle Sync и запустить на Android 8+.
Для сборки APK: Build -> Build Bundle(s) / APK(s) -> Build APK(s).

Примечание: это исходный проект, не собранный и не протестированный APK. В контейнере нет Android SDK/Gradle.
Захват экрана требует явного согласия пользователя каждый сеанс. Следующий этап — безопасно извлекать кадры
из MediaProjection и добавлять локальное распознавание графика. Реальные сделки не следует автоматизировать
без официального API платформы, независимого тестирования и жёстких ограничений риска.
